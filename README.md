## Basic_BeetleBot_Code
Some basic code for BeetleBot!

### IR Control
#### Introduction
You can use your IR control to control your Beetle Bot.
#### Keys
|↑|↓|←|→|
|-|-|-|-|
|Go forward|Go backward|Turn left on the spot|Turn right on the spot|

### Password
#### Introduction
You can set your own password for your Beetle Bot
#### Keys
|Number 0~9|#|
|-|-|
|Number of password|Lock and reset password input|
